Privacy Policy

Personal Assistant is a private app used only by its owner. It is not offered to the public and has no other users.

What it accesses

Only with the owner's permission, and only the owner's own accounts:

  • Email and calendars (Gmail, Google Calendar, iCloud Calendar) and contacts (iCloud), read-only, plus sending email only when the owner confirms each message.
  • Bank balances and transactions, read-only.
  • Instagram direct messages on the owner's own professional account, read-only. The app never sends messages, posts, follows or likes on Instagram.

How data is used

Data is used only to show the owner reminders, a weekly summary, and drafts for the owner to confirm. Short excerpts may be processed by Anthropic's Claude API to write those summaries; Anthropic does not use API data for model training.

Storage and sharing

Data is stored encrypted on the owner's own hardware. It is not sold, shared, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

Access can be revoked at any time from each provider (for example Google, or Instagram's Settings → Apps and websites). See data deletion instructions.

Contact

Via the developer contact email shown on the app's sign-in screens.
