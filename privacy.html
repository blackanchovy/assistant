Privacy Policy

Personal Assistant is a private app used only by its owner. It is not offered to the public and has no other users.

What it accesses

With the account owner's permission, it reads Gmail messages and Google Calendar events using read-only access. It never sends, modifies or deletes email or calendar data.

How data is used

Data is used only to show the owner reminders and a weekly summary. Short excerpts may be processed by Anthropic's Claude API to write those summaries; Anthropic does not use API data for model training.

Storage and sharing

Data is stored encrypted on the owner's own hardware. It is not sold, shared, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Via the developer contact email shown on the app's Google sign-in screen.
